# Лаборатория A/B-тестов

[Открыть курс →](https://roki112z.github.io/ab-handbook/) · [Платформа «Маяк» →](https://roki112z.github.io/ab-handbook/platform/)

Интерактивный курс на русском языке: 9 глав и 74 задания. Объяснения с нуля, формулы, симуляции, вопросы с обратной связью и рабочие памятки. Истории компаний снабжены первоисточниками.

Платформа «Маяк» устроена как рабочая консоль экспериментов команды Commerce:

- Список экспериментов с поиском и фильтрами.
- Обзор, результаты, протокол, метрики, качество данных, сегменты и история каждого подготовленного теста.
- Таблица метрик: контроль, вариант, фактические количества, эффект, интервал, p-value и интерпретация; раскрытие метрики и CSV.
- Каталог метрик с определениями, владельцами, окнами и демонстрационным SQL.
- Создание черновика с гипотезой, аудиторией, параметрами A/B, планом и проверками; фиксация протокола при запуске в песочнице, пауза, возобновление и остановка.
- Диагностика потерь данных и восстановление учебной витрины.
- Решения с обоснованием и неизменным снимком анализа, экспорт журнала.

Откройте [готовый отчёт EXP-104](https://roki112z.github.io/ab-handbook/platform/?experiment=EXP-104&tab=results) или создайте свой черновик. После каждой главы остаётся отдельная практика; её панель можно свернуть. Старые достижения и заметки сохранены.

В шапке есть кнопка «Палитра»: «Лаборатория», «Дневная», «Океан», «Ирис» и «Бумага».

Песочница работает без регистрации, на синтетических данных. Прогресс, черновики и решения сохраняются в браузере на вашем устройстве. Реальный трафик, SDK и рабочее хранилище не подключены; новые черновики не получают вымышленные результаты автоматически. В репозитории находится статическая версия для GitHub Pages.
