# Лаборатория A/B-тестов

[Открыть курс →](https://roki112z.github.io/ab-handbook/)

Интерактивный курс на русском языке: стандартная ошибка (SE), доверительные интервалы, p-value, планирование эксперимента, выбор метрик, дизайн и проверка качества данных. Объяснения с нуля, симуляции, вопросы с обратной связью и реальные истории Airbnb, eBay, Google, Microsoft, DoorDash и эксперимента с лососем.

Курс работает без регистрации. Прогресс сохраняется в браузере на вашем устройстве.

В этом репозитории находится готовая статическая версия для GitHub Pages. Источники исследований доступны в [разделе курса](https://roki112z.github.io/ab-handbook/sources/).

Новые главы: [план эксперимента](https://roki112z.github.io/ab-handbook/planning/) и [метрики](https://roki112z.github.io/ab-handbook/metrics/). Всего семь глав и 58 заданий; среди интерактивов — планировщик выборки и срока, симуляция мощности, выбор ролей метрик и решение о выпуске по доверительному интервалу.

Добавлены [глава 6 — дизайн эксперимента](https://roki112z.github.io/ab-handbook/experiment-design/) и [глава 7 — качество данных](https://roki112z.github.io/ab-handbook/data-quality/): закрепление варианта, единица назначения, отбор участников, A/A, SRM и поиск потерь. Шесть новых лабораторий и рабочие памятки.
