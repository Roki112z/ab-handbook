# Лаборатория A/B-тестов

[Открыть курс →](https://roki112z.github.io/ab-handbook/)

Интерактивный курс на русском языке: 9 глав и 74 задания. Объяснения с нуля, формулы, симуляции, вопросы с обратной связью и рабочие памятки. Реальные истории Airbnb, eBay, Google, Microsoft, Bing, DoorDash и эксперимента с лососем снабжены первоисточниками.

Новые главы:

- [8. Для кого сработало изменение?](https://roki112z.github.io/ab-handbook/segments/) — сегменты до воздействия, состав аудитории, парадокс Симпсона и прямое сравнение эффектов.
- [9. Как получить более точный ответ?](https://roki112z.github.io/ab-handbook/variance-reduction/) — прошлые данные, CUPED по отдельным покупателям, выигрыш точности и выбор признаков.

Шесть новых лабораторий: выбор сегмента, смешение аудитории, интервалы эффектов, восемь покупателей, корреляция и шум, проверка признаков для поправки.

[Оглавление](https://roki112z.github.io/ab-handbook/contents/) · [Словарь](https://roki112z.github.io/ab-handbook/glossary/) · [Источники](https://roki112z.github.io/ab-handbook/sources/)

Курс работает без регистрации. Прогресс и настройки сохраняются в браузере на вашем устройстве. В этом репозитории находится готовая статическая версия для GitHub Pages.
