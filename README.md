# Лаборатория A/B-тестов

[Открыть курс →](https://roki112z.github.io/ab-handbook/)

Интерактивный курс на русском языке: стандартная ошибка (SE), доверительные интервалы, p-value, планирование эксперимента и выбор метрик. Объяснения с нуля, симуляции, вопросы с обратной связью и реальные истории Airbnb, eBay, Google, Microsoft и эксперимента с лососем.

Курс работает без регистрации. Прогресс сохраняется в браузере на вашем устройстве.

В этом репозитории находится готовая статическая версия для GitHub Pages. Источники исследований доступны в [разделе курса](https://roki112z.github.io/ab-handbook/sources/).

Новые главы: [план эксперимента](https://roki112z.github.io/ab-handbook/planning/) и [метрики](https://roki112z.github.io/ab-handbook/metrics/). Всего пять глав и 42 задания; среди интерактивов — планировщик выборки и срока, симуляция мощности, выбор ролей метрик и решение о выпуске по доверительному интервалу.
